**TL;DR:** _BuntesLuebeck_ is a GPS-based competitive team game where players
virtually "paint" real-world areas and fight for territorial control in real
time. I designed, developed, and partially evaluated it as a Vue 3 + Directus
module inside the VernetzBar app; it has already been used at multiple public
events in Lubeck and is planned for future events in 2026.
