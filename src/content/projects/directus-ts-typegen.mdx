**TL;DR:** _Directus TS Typegen_ is an open-source Directus extension and CLI
that generates accurate TypeScript types from a Directus instance to improve
SDK type safety and developer experience. I built and actively maintain it
based on real production pain points, and to my knowledge it is currently the
only public package covering all Directus JSON field variants and relation
types (including M2A); it is already used by my team and publicly available (7
GitHub stars).
