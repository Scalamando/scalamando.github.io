TL;DR: I designed and developed the tech.festival landing page (first release in 2021, major redesign in 2025) for the yearly 4-day student workshop event by MaTZ. The implementation focused on responsive UX, technical SEO (including JSON-LD), performance optimizations (image compression and smooth animations), dynamic per-course OG image generation, and Moodle API integration in the first version; during the 2025 campaign it delivered about 10,000 impressions and 800 clicks, helping fill participant slots quickly, and it is currently live at https://matz-techfestival.de.
